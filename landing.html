01

How a request runs

Every request goes through the same five stages, whether it is one command or a whole routine. You see the plan before anything changes.

1Understand

Known commands are matched instantly, with no AI needed. Anything unfamiliar goes to the local AI, and its guess is shown to you first.

2Plan

Overlapping steps are merged and put in order, and dependencies are tracked. Two focus sessions become one, and the frontend waits for the backend.

3Ask

Steps that change things are marked ⚠. One approval covers the plan. Shutdown and delete need Windows Hello.

4Run

Steps run one by one against the current state. An app that is already closed is skipped instead of failing.

5Check

Results are read back: the volume level, whether the app is still running, whether the file exists. If a step can't be checked, it says ○ not checked.

03

What it won’t do

An assistant that controls your laptop should be predictable. These rules are enforced by the server, not left to the AI’s judgement.

  1. Act on a guess without showing youIf the AI planned a step, you see the plan and approve it first.
  2. Shut down, restart or delete on its ownThese need Windows Hello, and deleted files go to a trash folder first.
  3. Change your files without askingIt can open and read files anywhere, but any edit, rename, move or delete outside ~/jarvis waits for your OK. Windows and system folders are off-limits.
  4. Listen to the internetThe server only accepts connections from your own computer. Phone commands need an authenticator code.
  5. Claim success it didn’t checkA step that can’t be verified is marked ○ not checked, never a fake ✓.
04

Setup

No account and no subscription.

1Start it

Double-click Start JARVIS.bat. The first run installs what it needs and adds a desktop shortcut.

2Pick a brain

Choose Ollama for free, offline use, or paste an OpenAI, Claude, Gemini or Groq key. Guided setup checks it works.

3Talk to it

Try what can you do? or plan my day. Connect your phone later from Settings.

Needs: Windows 10 or 11, Node.js 18+, and Chrome or Edge for voice. Optional: an NVIDIA GPU for the local model (a 6 GB RTX 3050 runs a 4B model comfortably), plus Python, g++ and VS Code for the coding tools.
